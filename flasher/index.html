ESP32-S3 Exit Node Flasher

Flash firmware ลงบอร์ด ESP32-S3 (N16R8) แล้วตั้งค่าให้ต่อออกไปหา VPS broker • Chrome / Edge เท่านั้น

1 เสียบบอร์ดแล้วกดติดตั้ง

เสียบ ESP32-S3 เข้าพอร์ต USB (ใช้พอร์ต USB ของ S3 หรือกดปุ่ม BOOT ค้างแล้วแตะ RST หากเข้าโหมดแฟลชไม่ได้) แล้วกดปุ่มด้านล่าง เลือกพอร์ต Serial ของบอร์ด

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS หรือ http://localhost เท่านั้น

เวอร์ชัน firmware: NAT Router v2.4.21-mux1.2 + rproxy mux1 (one multiplexed TLS link, 40 streams, 64 KB TCP buffers, auto-provision, OTA) • target: ESP32-S3 16MB flash / 8MB PSRAM

2 ต่อ WiFi บ้าน (STA)

หลังแฟลชเสร็จ บอร์ดจะเปิด WiFi ชื่อ ESP32_NAT_Router (เปิด ไม่มีรหัส)

  1. เชื่อมต่อ WiFi ESP32_NAT_Router ด้วยมือถือหรือโน้ตบุ๊ก
  2. เปิด http://192.168.4.1 (หรือ http://esp32-nat-router.local)
  3. ใส่ชื่อ/รหัส WiFi บ้าน (อินเทอร์เน็ตไทย) ในหน้า STA แล้วกด Save & Reboot

บอร์ดนี้คือ “ปลายทางออกเน็ต” — ลูกค้าที่ต่อผ่าน VPS จะออกเน็ตด้วย IP ของ WiFi บ้านที่ตั้งไว้ตรงนี้

3 เชื่อมต่อกับ VPS อัตโนมัติ

ไม่ต้องตั้งค่าอะไรเพิ่ม — firmware นี้ฝังข้อมูลเซิร์ฟเวอร์ไว้แล้ว (เข้ารหัส TLS, ยืนยันด้วยใบรับรองที่ฝังในบอร์ด) ทันทีที่ต่อ WiFi บ้านได้ บอร์ดจะต่อไปหา VPS เอง

ดูสถานะได้ที่หน้าแรกของบอร์ด (192.168.4.1 ตอนตั้งค่า หรือ IP ที่ได้จาก WiFi บ้านหลังจากนั้น) บรรทัด Proxy service:

  • online — เชื่อมต่อ VPS สำเร็จ พร้อมใช้งาน
  • connecting / waiting for WiFi — กำลังต่อ รอสักครู่
  • error (rejected) — เซิร์ฟเวอร์ปฏิเสธบอร์ดนี้ (ถูกบล็อก) ติดต่อผู้ดูแล

เมื่อ WiFi บ้านใช้งานได้ บอร์ดจะปิด WiFi ESP32_NAT_Router ของตัวเองเพื่อความปลอดภัย และเปิดกลับอัตโนมัติถ้า WiFi บ้านหลุดนานกว่า 90 วินาที บอร์ดจะปรากฏใน Dashboard ของผู้ดูแลตาม MAC address
