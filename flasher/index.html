ติดตั้ง Firmwareตั้งค่า WiFiเวอร์ชันทั้งหมด

ESP32 Exit Node Flasher

Flash firmware ลงบอร์ด ESP32-S3 N16R8 หรือ ESP32-C3 Super Mini แล้วตั้งค่าให้ต่อออกไปหา VPS broker • Chrome / Edge เท่านั้น

1 เสียบบอร์ดแล้วกดติดตั้ง

เสียบบอร์ดเข้าพอร์ต USB แล้วกดปุ่มด้านล่าง เลือกพอร์ต Serial ของบอร์ด เบราว์เซอร์จะตรวจว่าเป็นชิป S3 หรือ C3 แล้วเลือก image ให้ถูกรุ่นเอง (S3: ใช้พอร์ต USB ของบอร์ด ถ้าเข้าโหมดแฟลชไม่ได้ให้กด BOOT ค้างแล้วแตะ RST • C3 Super Mini: เสียบ USB-C ได้เลย ไม่ต้องกดปุ่ม)

เบราว์เซอร์นี้ไม่รองรับ Web Serial — ใช้ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ ต้องเปิดผ่าน HTTPS หรือ http://localhost เท่านั้น

เวอร์ชัน firmware: NAT Router v2.4.21-mux1.2 + rproxy mux1 (one multiplexed TLS link, auto-provision, OTA) • บอร์ด: ESP32-S3 N16R8 (40 streams) และ ESP32-C3 Super Mini (4 streams)

2 ต่อ WiFi บ้าน (STA)

หลังแฟลชเสร็จ บอร์ดจะเปิด WiFi ชื่อ ESP32_NAT_Router (เปิด ไม่มีรหัส) พร้อมหน้าตั้งค่า WiFi หน้าเดียว

  1. เชื่อมต่อ WiFi ESP32_NAT_Router ด้วยมือถือหรือโน้ตบุ๊ก (มือถือส่วนใหญ่จะเด้งหน้าตั้งค่าขึ้นมาเอง)
  2. ถ้าไม่เด้ง ให้เปิด http://192.168.4.1
  3. ใส่ชื่อ/รหัส WiFi บ้าน (อินเทอร์เน็ตไทย) แล้วกด Save & Reboot

บอร์ดนี้คือ “ปลายทางออกเน็ต” — ลูกค้าที่ต่อผ่าน VPS จะออกเน็ตด้วย IP ของ WiFi บ้านที่ตั้งไว้ตรงนี้

3 เชื่อมต่อกับ VPS อัตโนมัติ

ไม่ต้องตั้งค่าอะไรเพิ่ม — firmware นี้ฝังข้อมูลเซิร์ฟเวอร์ไว้แล้ว (เข้ารหัส TLS, ยืนยันด้วยใบรับรองที่ฝังในบอร์ด) ทันทีที่ต่อ WiFi บ้านได้ บอร์ดจะต่อไปหา VPS เอง

เมื่อ WiFi บ้านใช้งานได้ บอร์ดจะปิด WiFi ESP32_NAT_Router และหน้าตั้งค่าของตัวเอง (ตั้งแต่ firmware 2.4.22 บอร์ดไม่มีหน้าเว็บจัดการอีกต่อไป) และเปิดกลับอัตโนมัติถ้า WiFi บ้านหลุดนานกว่า 90 วินาที เพื่อให้ตั้ง WiFi ใหม่ได้

ดูสถานะบอร์ดได้ที่ Dashboard ของผู้ดูแล (Devices → ตาม MAC address): online / offline, IP ทางออก, ปริมาณใช้งาน, เวอร์ชัน firmware และชิป (S3 / C3) บน C3 Super Mini ไฟ LED สีน้ำเงินบนบอร์ดจะติดเมื่อต่อ WiFi บ้านได้

4 จัดการผู้ใช้ / ขาย

เพิ่ม/ลบผู้ใช้ ตั้งความเร็ว โควตา และวันหมดอายุ ผ่าน Admin API หรือ GOST UI

เวอร์ชันทั้งหมด (ใหม่สุดอยู่บน)

เลือกเวอร์ชันไหนก็ได้จากช่อง “เวอร์ชัน firmware” ด้านบน รวมถึงถอยกลับไปเวอร์ชันเก่า บอร์ดที่ต่อ VPS อยู่แล้วอัปเดต/ถอยเวอร์ชันผ่าน Dashboard → Devices → Update FW ได้โดยไม่ต้องเสียบสาย
